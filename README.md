# Intake

A choice-driven browser game about prison intake. Create a character, make
decisions through a 10-chapter story, and land on one of eight endings
depending on the path you take.

Single self-contained file (`index.html`) — no build step, no dependencies
beyond a Google Fonts stylesheet. Open it directly in a browser, or deploy
it as a static site (drag-and-drop onto Netlify, GitHub Pages, etc.).

## How it works

- Character creation: pick a name and one of four backgrounds, each with
  different starting stats.
- Choices are tracked across seven stats/flags (Muscle, Smarts,
  Connections, Respect, Health, Sanity, Heat) that gate later options.
- Endings are computed from your final stats and the flags you picked up
  along the way — from a clean parole to getting pulled back in.

This is fiction. No affiliation with any real facility, agency, or person.
